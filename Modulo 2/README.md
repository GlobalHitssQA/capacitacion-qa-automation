Sobre la terminal: Es un programa en el que se pueden implementar comandos directamente, pudiendo interactuar de forma mas directa con el equipo sin necesidad de utilizar una interfaz gráfica.

Navegación en la terminal: 
-cd (Change Directory): Se utiliza para navegar entre directorios (carpetas). Te permite entrar a una carpeta, salir de ella o moverte a una ruta específica. Si escribes cd sin nada más, te mostrará la ruta del directorio en el que te encuentras actualmente. Un ejemplo es cd /d D:\Imagenes
-dir (Directory): Este comando sirve para listar el contenido del directorio en el que estás posicionado. Te mostrará una lista de todos los archivos y subcarpetas contenidos en esa ubicación, junto con detalles como el tamaño y la fecha de modificación. Esto incluye los archivos ocultos.
